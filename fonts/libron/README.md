# Libron

Libron v0.30 by Nico Verbruggen, https://github.com/nicoverbruggen/libron.
Built unmodified from the v0.30 tag with the author's `build.py`, which
writes these WOFF2 files. Libron descends from Readerly, which descends
from Newsreader, the heading face on this site.

Licensed under the SIL Open Font License 1.1 (see OFL.txt). "Libron" is a
Reserved Font Name: if these files are ever subset or otherwise modified,
the modified font must be renamed.

The site uses Libron for chapter body text only.
