# VSU Context

*The Strategic Plan, DIGITS, and the path into the institution*

CAMPUS is written for VSU, so it must fit VSU's plans without claiming a place in them. The Strategic Plan 2017–2027 serves as an alignment framework, not a mandate. DIGITS is context, and CAMPUS's relationship to it is VSU's decision. [Established]

## Strategic Plan 2017–2027

The plan's seven goals are reference points for checking whether a CAMPUS idea addresses a real VSU priority. They are not evidence that VSU needs CAMPUS. [Established]

| VSU goal | Where CAMPUS might contribute | Through |
| --- | --- | --- |
| World-Class Education | Finding programs, people, and learning resources; later, learning records | Network; later directions |
| Globally Competitive Science and Technology | Finding expertise and research | Later directions |
| Empowered Communities | Community spaces where official and community information stay distinct | Network |
| Sustainable Resource Generation | Connecting facilities, services, expertise, and partners | Later directions |
| Client-Centered Governance | Services that are easier to find, with official information clearly marked | Network |
| Versatile Spaces for Innovation | Places as part of the model; later, a spatial campus | Network; later directions |
| Strong Alumni Engagement | Lasting ties between alumni, programs, and current students | Network, later |

Every row is a possible contribution, not a demonstrated one. [Proposed] (v0.1 §10.4)

## DIGITS

- DIGITS is a proposed 2027–2029 digital transformation roadmap presented in the President's Third State of the University Address. [Established] A citation to the address still needs to be added. [Unresolved]
- Its named components are OneVSU Mobile, OneVSU Portal, OneVSU ERP, an Executive Dashboard, e-attendance, and MATS. [Established]
- v0.1 expanded the name as "Digital Innovation for Green, Intelligent and Transformative Systems" without a source. [Unresolved]
- This document assumes nothing about DIGITS's architecture, status, ownership, data, interfaces, or governance. [Established]

v0.1 listed six possible relationships between CAMPUS and DIGITS (v0.1 §10.9). All remain open, and VSU decides among them:

1. A complementary layer alongside DIGITS.
2. A test environment for ideas before institutional scale.
3. A component of a broader VSU ecosystem.
4. An independent system linked through approved interfaces.
5. Superseded, because the capability already exists or is planned elsewhere.
6. Research only.

## The path into the institution

The first pitch goes to OVPSAS, because the social/academic network would benefit that office most. [Proposed] Progress is measured on a seven-stage ladder ([Chapter 11](11-roadmap.md)): interest is not permission, and permission is not a pilot. As of October 2026, no VSU office has reached any stage. [Established]

Before proposing any integration, CAMPUS has to learn what VSU already runs: which systems exist, who owns them, which data is authoritative, what interfaces exist, how identity works, which policies apply, and what is already planned. The point is not to justify CAMPUS. It is to find where CAMPUS is useful, unnecessary, complementary, constrained, or inappropriate. [Established] (v0.1 §10.10)

## Own or reference

For every kind of data, the test is whether CAMPUS owns it or only points to it (v0.1 §10.11).

| Data | CAMPUS role | Question VSU answers |
| --- | --- | --- |
| Identity | Reference | Which identity system is authoritative? |
| Enrollment and records | Reference | Which academic system owns them? |
| Courses | Reference or cache | Which system holds current course data? |
| Facilities | Reference | Which office maintains them? |
| Events and announcements | Represent, with the source shown | Where is the official record? |
| Community discussion | Owned by the network | What governance applies? |

Owning only what nobody else owns keeps CAMPUS from becoming an accidental second system of record. [Established]
